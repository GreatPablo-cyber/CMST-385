Project Proposal

Project Concept

Website Overview

For this project I will be creating a website for an Magic The Gathering store locator. The locator will be used to find local shops in the area and give descriptions of the shop, such as ratings and reviews. The intended audience includes new magic players, competitive players, collectors, and hobby enthusiasts.

Features

An interactive map that allows the user to move around and find stores to get reviews on the store before they go.

  1. Store Locator
  2. Interactive Map

Website Organiztion

The website will have a total of five pages. Page one will be the home page and will have navigation to "How to Play", "Shops Nearby", and "Report Issue". Page two will consist of a description of how to play Magic the Gathering with links to the home page, the next page of finding a shop, and then the report an issue page. The next age will be the shops nearby page and will have the store locator on it. To include links to the home page, the next page of shop descriptions, and the report an issue page. then the next page will have a description of the shop that was chosen with links to the home, how to play page, shops nearby page so the user can go back, and the report an issue page. The final page will be the report an issue page for the user to report an issues or bugs on the website. With links to the home page, how to play page and the shops nearby page.

  • Home Page
  • How to Play
  • Shops Nearby
  • Shop Details
  • Report Page
